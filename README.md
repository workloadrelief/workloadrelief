# Workload Relief LLC

**Practical marketing automations for local service businesses.**
We build the small but always-on tools that local service businesses don't have time to set up themselves — so their leads get answered, logged, and followed up while they're out doing the actual work.
Based in Central Florida. Two people: Thomas (Founder — builds and operations) and Walter (Partner — sales and client relationships).
  
  ---
  
  ## What we build
  - **Missed-call text-back** — every missed call gets an SMS reply within seconds, the call is logged, and the owner is
   notified
  - **Contact-form auto-response** — website forms reply instantly, route to the right inbox, and append to a lead log
  - **Voicemail handling** — voicemails are transcribed, emailed with the recording, and the lead is captured
  automatically
  - **Review-request automation** — completed jobs trigger a follow-up SMS asking for a Google review
  - **Lead dashboards** — owners get one URL that shows weekly volume, lead sources, response time, and conversion
  - **Light websites** — Carrd or Squarespace landing pages for service businesses that don't need anything bigger
    
  ---
  
  ## Stack
  `n8n` · `Twilio` (Voice, SMS, Studio Flows, Functions) · `Google Apps Script` · `FieldworkHQ` · `Google Sheets` · `Carrd` · `Squarespace` · `OpenAI Whisper`

  How we build:
  - Simplest tool that solves the real problem — no vendor lock-in for the client
  - Every production workflow has a Sandbox sibling; test there first, promote after one live test passes
  - Each automation is documented so a non-technical owner can read it and understand what's happening
